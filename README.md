# DM-J10010L-2EC

## 概述
- 这是 DM-J10010L-2EC 减速电机资料入口。
- 该型号的输出轴编码器与其他关节电机的编码器类型不同。
- 进行输出轴校准时，上位机可能会显示报错，这是已知现象。
- 只要电机在校准过程中正常转动，且校准完成后上位机串口界面打印出校准角度信息，就可以认为校准通过。
